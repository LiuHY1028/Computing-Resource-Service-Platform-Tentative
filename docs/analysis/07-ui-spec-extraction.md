# UI 设计规范提取

> 来源：`docs/source/03-ui-design-spec.pdf.pdf`，共 18 页。
>
> 检查方式：PDF 全页渲染后逐页视觉检查，并结合页面内可读文字与尺寸标注整理；未只依赖文本抽取。
>
> 适用范围：本文件只约束布局、视觉和交互表现，不决定计费、审批、权限、资源状态或其他业务规则。
> 品牌说明：PDF 中的 OneAiNexus 名称与 Logo 仅代表设计规范来源，当前产品正式名称与 Logo 均未确认，后续实现不得硬编码。

## 1. 证据级别与使用规则

| 标记 | 含义 | 后续实现规则 |
|---|---|---|
| 明确标注 | PDF 页面直接给出尺寸、颜色、文字规则或状态名称 | 可转成 Design Token 或组件默认值；若与其他页冲突，按本文件的冲突裁决处理 |
| 重复归纳 | 同一数值或模式在多个组件示例中反复出现 | 可作为公共组件规则，但需保留原始页码 |
| 视觉推断 | 页面能看出关系或样式，但没有可靠数值标注 | 只能作为暂定实现方向，不得宣称是精确设计参数 |
| 无法识别/缺失 | PDF 未提供、标注含混或无法从静态画面可靠判断 | 不得目测补成精确参数；进入设计待确认清单 |

冲突优先级：同一组件的专用页明确标注优先于全局色板的泛化推断；仍有明显自相矛盾时，使用本文列出的临时值并保留待设计确认标记。UI 规范与业务需求冲突时，业务需求决定“做什么”，UI 规范决定“如何呈现”。

## 3. Design Tokens

### 3.0 品牌资产（仅作规范来源记录）

- p.1 提供主标识的彩色、单色和线框三种版本，均标注为 SVG；另提供彩色、品牌色、勾线、彩色 2、勾线 2 五种应用图标示例。（p.1，明确标注）
- p.1 展示了图标与 OneAiNexus 文字组合的应用示例，但未给出最小尺寸、安全区、深浅背景选型、禁用变形方式或下载资产路径。（p.1，缺失）
- 这些资产只能帮助理解规范来源的品牌表达。当前产品的正式名称和 Logo 未确认，原型与代码必须使用可配置占位品牌，不得直接复制或重绘该 Logo。（任务约束）

- 中文与英文示例均标为 `Misans VF`。（p.3，明确标注）
- 字体调用顺序原文为 `PingFangSC/Microsoft YaHei → simsun → sans-serif`；若环境支持，开启字体平滑属性。（p.3，明确标注）
- `Misans VF` 与字体调用顺序之间未明确谁是首选。临时建议：产品运行时优先使用可合法交付且真实可用的 MiSans VF；不可用时按 PDF 给出的系统字体回退顺序。字体文件与授权必须由设计/工程确认。（p.3，缺失项）

### 4.4 栅格

- 基准视口为 1080p；内容区标注宽度为 **1704 px**。（p.16，明确标注）
- 采用 24 栏栅格，左右边距各 20 px，栏距 20 px。（p.16，明确标注）
- 常用等分：`6 + 6 + 6 + 6`（4 卡片）、`8 + 8 + 8`（3 卡片）。（p.16，明确标注）
- 自动换行时保持左对齐；示例包括 6 张 `span 6` 卡片和 5 张 `span 8` 卡片。（p.16，明确标注）
- 主次布局示例为 `16 + 8`；居中布局示例为 `6 + 12 + 6`。（p.16，明确标注）
- PDF 没有给出窄屏断点、最小内容宽度、移动端方案或表格横向滚动策略；必须由工程阶段补充响应式规则，不能按画板绝对坐标复刻。（p.16，缺失）

## 8. 交互约束

1. 所有可点击按钮必须产生可观察反馈；提交中按钮进入 Loading 并阻止重复提交。Loading 视觉需新增规范。（产品交互基线；PDF 未定义）
2. Disabled 不能只依赖灰色；需要邻近说明或 Tooltip 解释原因。（p.9、p.15 + 产品交互基线）
3. 输入错误使用字段级错误文字，并保持 Focus/错误聚焦态可辨识。（p.10）
4. Select 展开层使用下拉阴影；弹窗/浮层需要正确层级、滚动与焦点管理，这些参数需补充。（p.8、p.12、p.13）
5. 收起侧栏仅显示图标时，必须提供 Tooltip 与可访问名称。（p.5、p.15）
6. 表格空数据与筛选无结果要区分；p.17 只给空表格视觉，筛选无结果文案与重试态需扩展。
7. 页面与表单布局使用栅格和正常文档流，不按 PDF 画板坐标大量绝对定位。（p.6、p.16、p.18）
8. 颜色不是唯一状态信号；选中、错误和成功应同时具备图标、文本或结构变化。（p.10-p.13，综合规则）

## 9. 禁止事项

- 不得把 OneAiNexus 名称、Logo 或应用图标当作当前产品最终品牌。（p.1）
- 不得使用 PDF 截图代替真实页面、文本、图表或控件。
- 不得机械复刻 1920 × 1080 画板的绝对坐标；使用 24 栏与响应式规则。（p.16）
- 不得在普通白底页面使用幽灵按钮；不得用阴影装饰所有容器。（p.8、p.9）
- 不得用设计规范中的“删除、启用、重试”等示例反推业务允许的操作。（p.17）
- 不得把 HostPath/NFS/K8S Pod 等业务底层术语仅因 UI 有空间就直接暴露给普通用户；术语策略以需求基线为准。
