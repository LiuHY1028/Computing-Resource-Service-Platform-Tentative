## 4. 决策维护规则

- 待确认项获得正式结论后，新增一行决策并在原行注明覆盖关系，不直接抹掉历史。
- 对 `DEC-010` 的真实基础设施中间状态及 `DEC-023、DEC-028、DEC-034、DEC-038、DEC-041` 的实现只能采用可替换的临时方案；物理机交付字段以 `DEC-043` 为准，前端交易与状态边界以 `DEC-045～047` 为准。
- 任何新增价格、支付、审批、角色权限、订单/资源状态、删除/释放、续费或退款规则，必须新增决策记录和明确来源。
- 视觉规范中的名称、Logo、示例数据和组件状态不自动构成业务决策。
