# 资源精细化跨模块影响清单

| 数据事实来源 | 读取该数据的模块 | 修改该数据的模块 | 本次必须同步修改的范围 | 不受影响的范围 |
|---|---|---|---|---|
| 资源目录与资源 Store | 资源列表/详情、订单、存储、镜像、软件、网络、操作记录 | 资源操作、名称/项目/标签管理、生命周期申请 | 云服务器与物理机差异字段、状态/健康、有效期、标签项目及关联名称 | 商城商品事实与购买规格选择 |
| 云服务器生命周期字段 | 云服务器列表/详情、订单、操作记录 | 续费、自动续费、批量操作 | 到期状态、预计到期时间、处理中状态、申请关联 | 真实价格、扣款、支付与正式审批 |
| 物理机使用期限字段 | 物理机列表/详情、订单、操作记录 | 延期申请、批量延期 | 使用期限、延期状态、预计到期时间、责任人 | 真实硬件调度与审批系统 |
| 存储 Store 与资源磁盘事实 | 存储列表/详情、资源存储页、订单、操作记录 | 扩容申请、挂载、卸载 | 容量计算、性能、角色差异、资源关联和跳转 | 未确认的 RAID 修改与底层存储编排 |
| 订单 Store | 订单列表/详情、资源详情 | 新购、续费、延期、变配、扩容、重装、释放申请 | 申请类型、资源、预计到期、配置变化、处理记录 | 金额、账单、退款与支付 |
| 统一操作记录 Store | 操作记录页、资源/存储详情 | 所有可追溯资源和存储操作 | 对象关联、操作类型、前端受理结果与跳转 | 打开连接信息等只读查看 |
| 镜像、软件与网络 Store | 各自列表、详情与资源详情 | 各模块既有操作 | 关联资源存在性、当前名称/项目/标签、详情跳转 | AI 平台 Notebook、训练、推理与 Token 流程 |
| 商城商品与购买配置 | 商城、购买页、资源创建快照 | 商城 Store 与购买流程 | 验证资源规格兼容，不复制商品数据 | 商品筛选、视觉与既有购买主流程 |
| Hash 路由与离线入口 | AppShell、全部详情跳转、离线 HTML | 路由配置与构建脚本 | 详情 ID、前进后退刷新、file:// 单文件可达 | 外部 API、服务端路由和外部资产 |
