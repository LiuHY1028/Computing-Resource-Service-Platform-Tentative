# 纯前端迁移清单

## 删除

- `VITE_DATA_MODE`、API/fixture 双模式与运行时配置。
- Repository/Service 请求边界、人工请求延迟、请求取消、模拟读取失败和查询参数故障场景。
- 仅为远程读取存在的 Loading、Error、Retry 状态与后端接入说明。
- 服务端部署、接口地址和响应映射语义。

## 替代

- 页面直接读取随应用打包的领域数据，并通过各领域 Store 执行同步查询和本地动作。
- 内存状态是运行时事实来源；可选浏览器存储只用于刷新体验增强，不可用时静默退回内存。
- 表单保留提交中、校验、确认与结果反馈；搜索无结果、空数据、禁用和路由不存在继续保留。

## 保留

- 商城筛选、配置校验、资源操作可用性、存储挂载、镜像、软件、网络、订单和操作记录等纯前端领域逻辑。
- 资源、订单、存储、镜像、软件、网络和操作记录之间的稳定关联 ID。
- 已确认页面、交互、跨模块跳转及正式产品文案。

## 离线交付

- 正式入口使用 Hash 路由。
- `npm run build:offline` 将 JavaScript、CSS、MiSans VF、图标和内置数据内联到 `release/算力资源服务平台.html`。
- 产物可通过 `file://` 直接打开，不依赖服务器、Node、同目录资产或外部网络。
