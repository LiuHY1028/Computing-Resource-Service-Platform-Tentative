# 公共产品页参考重构与浏览器验收

## 参考结构

参考附件原图尺寸为 1912 × 3558，裁切从蓝色 Hero 开始，未包含顶部导航。可确认的结构节奏为：集中蓝色 Hero、约 100px 四项能力条、居中内容版心、三列价格矩阵、约 60–64px 数据排行表行，以及说明桥接区和深色多栏页尾。

实现采用 56px 白色顶栏和 1200px 最大内容宽度。1920px 视口下左右留白各 360px，占视口 18.75%，接近参考图约 19.6% 的留白比例。商城 Hero 文案与图形为 47/53，软件中心为 54/46，用内容比例区分硬件购买和软件发现两种产品表达。

## 浏览器回归

- 三种视口下页面根节点、产品页滚动区和数据表均无非预期横向溢出。
- 商城类型切换、搜索、规格对比筛选、云服务器与物理机配置入口及返回状态可用。
- 软件已安装快捷筛选、分类联动、详情、安装版本、目标资源下拉和兼容资源选择可用；确认安装只在信息完整时可用。
- 公共导航进入控制台、Hash 刷新、浏览器前进后退、旧路由重定向、默认路由和 404 均正常。
- 浏览器控制台没有 warning 或 error。
