# 全项目交付说明

## 已完成模块

资源商城、云服务器与物理机配置、两类资源列表与详情、存储管理、镜像管理、软件中心、网络与访问、订单列表与详情、操作记录和 404 均已接入正式路由。全部管理页具备适用的搜索、组合筛选、分页、表单校验、确认、反馈与页面状态。

## 正式路由

正式路由集中定义于 `src/app/routes.ts`，装配于 `src/app/router.tsx`。一级入口为 `/marketplace`、`/resources/cloud-servers`、`/resources/physical-machines`、`/storage`、`/images`、`/software`、`/network-access`、`/orders` 和 `/operation-records`；对象详情使用对应动态 ID 路由。开发检查路由只在开发环境注册。

## Repository 与持久化边界

资源、存储、镜像、软件、网络、订单和操作记录分别通过领域 Repository 读写，页面不直接修改散落数据。资源 Repository 保持计算资源身份、规格和基础操作边界；其他领域以资源 ID 建立关联。`src/features/platform/persistence.ts` 提供版本化 `localStorage` 适配，数据损坏或版本不兼容时只恢复对应领域；购买表单草稿使用版本化 `sessionStorage`。

## 跨模块联动

- 配置提交创建申请快照并进入订单详情，不自动创建计算资源。
- 已交付申请可进入关联资源；资源详情可查看相关申请和统一操作记录。
- 存储挂载、镜像关联、软件安装和网络规则与资源详情读取同一领域数据。
- 存储详情和资源详情支持双向跳转；镜像、软件、网络和操作记录提供关联对象入口。
- 所有可变更操作写入统一操作记录。

## 浏览器验收范围

在 1920×1080 与 1366×768 视口检查全部正式菜单、列表与详情、搜索筛选、分页、Tabs、表单、Modal、新增编辑删除、提交反馈、返回、刷新、前进后退、键盘操作、Portal、控制台和页面横向溢出。生产预览同时检查未知路径与 `/__dev/*` 的 404 行为。浏览器检查不生成或保存页面截图。

## 当前真实服务边界

未连接真实支付、计费、审批、库存、资源编排、存储系统、镜像仓库、远程软件安装、安全组、公网 IP 分配、监控、账号权限或凭据服务。应用内的“已提交”“处理中”“等待资源准备”等状态只表示前端 Repository 已受理记录；只有安全初始数据可展示既有可用、已生效、已安装或已交付状态。

## API 接入边界

后端接口按现有领域拆分为：资源目录与资源详情、配置申请、存储空间与挂载任务、镜像目录与导入任务、软件目录与安装任务、网络规则变更、统一操作记录。接口应返回稳定对象 ID、可追踪任务状态和更新时间；页面继续通过 Repository 适配远程数据，避免把传输细节扩散到组件。
