# 全项目交付说明

资源商城、云服务器与物理机配置、两类资源列表与详情、存储、镜像、软件、网络、订单、操作记录和 404 均使用正式 Hash 路由。菜单、详情、返回和跨模块跳转由 React Router 管理，可在 `file://` 下前进、后退和刷新。

各领域通过 `data/` 中的打包数据和 `state/` 中的前端状态边界读写。资源 ID、存储 ID、镜像 ID、订单编号和操作记录关联保持一致；配置提交创建订单快照，资源、存储、镜像、软件和网络操作会更新对应状态并追加操作记录。

`src/features/platform/persistence.ts` 只提供可选的安全持久化。内存状态始终可用，浏览器存储读取或写入失败会静默回退，不影响核心操作。

独立交付文件由 `npm run build:offline` 生成，并由 `npm run verify:offline` 检查脚本、样式、MiSans VF、路由、资源引用与文件结构。正式产物不注册开发路由，不依赖服务器、外部文件或网络。

应用不生成未实际发生的支付、审批、库存、资源编排、IP、密码、密钥、凭据或基础设施完成结果；提交后的反馈只表达受理、处理或等待交付。
