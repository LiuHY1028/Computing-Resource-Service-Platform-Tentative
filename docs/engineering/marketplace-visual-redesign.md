# 资源商城视觉重构

## 范围与结论

本次重构仍属于 Task 05A，只调整 `/marketplace` 的页面视觉、商品陈列和信息密度。商品类型、字段含义、Mock 数量、数据访问层、筛选规则、页面状态、购买入口、AppShell、正式菜单、公共组件 API 和依赖均未改变。

总体方向为“紧凑专业型的信息密度 + 高级彩色型的视觉表现”。页面继续遵循项目 UI 规范，同时吸收权益中心类页面的浅色分区、分类节奏和密集商品卡模式，不复制营销业务或品牌资产。

## 页面结构变化

### 商城头部

PageTitleBar 和 AppShell 保持不变。标题下新增约 142 px（1920）/126 px（1366）的紧凑导视区，包含“计算资源目录”标识、核心定位、两类资源说明和演示数据声明。背景只使用低饱和蓝白—浅紫局部渐变，没有图片、伪图标或大型 Hero。

资源类型仍复用公共 `TitleBarTabs`。页面只覆盖本页外观，将 Tabs 组织为居中的分类导航带；手动激活键盘模型、ARIA 和 URL 查询参数逻辑不变。

### 筛选区域

筛选区改为独立浅蓝白面板，搜索、站点、计算类型和配置状态在 1920/1366 默认状态均保持一行。24 栏跨度调整为：搜索 8 栏、站点 6 栏、计算类型 5 栏、配置状态 5 栏；GPU 型号和数量在适用时进入自然第二行。

默认筛选区实测为 1920 云服务器 120 px、物理机 130 px；1366 云服务器 112 px、物理机 122 px。已选条件、结果数量和重置仍使用原逻辑，Select/MultiSelect 继续由公共 Portal 呈现。

### 商品区标题

通用“资源规格”改为类型导向标题：

- 云服务器：`云服务器精选规格`；
- 物理机：`物理机整机资源`。

标题旁显示当前结果数量，副标题明确结果来自本地演示资源。强调色只服务目录识别，不表示可用性、价格或推荐等级。

## 商品卡结构

`ResourceProductCard` 由三个明确表面区组成，并保持五层信息顺序：

1. 浅色类别头部：资源类型、CPU/GPU 类型、文字状态和商品名称；
2. 白色主体：2 × 2 核心指标；
3. 补充信息：站点、适用时的加速卡数量和整机摘要；
4. 极浅类别色操作带：辅助说明或不可配置原因；
5. 公共 `Button`：保持原“立即配置”路由和禁用行为。

核心指标规则：

- 云服务器 CPU：CPU 规格、内存、计算类型、默认系统盘；
- 云服务器 GPU：GPU 型号作为主要视觉锚点，同时展示 CPU、内存和默认系统盘；GPU 数量保留在补充信息；
- 物理机 CPU：整机 CPU 占满一行，内存和计算类型组成第二行；
- 物理机 GPU：GPU 型号、GPU 数量、整机 CPU 和内存组成完整 2 × 2 指标区。

物理机 CPU、GPU 型号和整机摘要在空间不足时单行截断，并由可聚焦 `Tooltip` 提供完整内容。核心字段仍使用 `dl/dt/dd` 语义，CPU 卡不显示虚假 GPU，云服务器 `30 GB` 仍只表示默认系统盘存储容量。

卡片根、头部、主体和操作区均无固定 `height`、无多余 `min-height`、无 `margin-top: auto` 或填空用弹性区域。实测结构块占卡片高度约 99.1%，剩余约 0.9% 为边框计算差异；原先大片同色白表面被类别头部和操作带分组替代。

## 商城页面装饰 Token

以下颜色只声明在 `.marketplace-page`，不进入全局 `src/styles/tokens.css`，也不改变功能语义色：

| Token | 用途 |
|---|---|
| `--marketplace-accent-blue` | 云服务器 CPU、目录主强调 |
| `--marketplace-accent-cyan` | 物理机 CPU、整机目录强调 |
| `--marketplace-accent-violet` | GPU 类别的辅助强调 |
| `--marketplace-surface-blue` | 商城背景、云服务器浅表面 |
| `--marketplace-surface-cyan` | 物理机浅表面 |
| `--marketplace-surface-violet` | GPU 和演示数据浅表面 |

映射关系：云服务器 CPU 为蓝色；云服务器 GPU 为蓝—紫；物理机 CPU 为青色；物理机 GPU 为青—紫。可配置继续使用全局成功色，不可配置继续使用中性色、可见原因和禁用按钮。页面级三组前景/浅表面对比度实测分别为 5.56、4.66、5.27，均不低于普通文本 4.5:1 的目标。

## Hover、Focus 与动效

- 可配置卡 Hover：类别边框增强、现有轻量阴影、上移 2 px；卡片根保持普通指针；
- 不可配置卡 Hover：无位移、无阴影、无可点击暗示；
- 键盘 Focus：卡片 `:focus-within` 使用公共 Focus 阴影，长字段和整机摘要触发器有清晰 `:focus-visible`；
- Tooltip：鼠标和键盘均可读取长 CPU、GPU 型号、整机摘要及不可配置补充原因；
- Reduced Motion：关闭卡片过渡和位移。

## 功能与边界回归

- 云服务器/物理机 Tabs、`type` 查询参数和刷新恢复保持不变；
- 搜索、站点、计算类型、GPU 型号/数量、配置状态、多条件组合、FilterTag 和重置保持不变；
- Loading、Error/Retry、Empty、No Result 和 Disabled 使用原状态逻辑；
- 当前每页大小为 6，云服务器默认恰好 6 项、物理机 4 项，因此默认页面正确不显示分页；`MarketplaceResults` 组件测试继续用既有商品 fixture 和 `pageSize=1` 覆盖分页分支；
- 两类可配置商品仍进入原购买占位路由并可返回对应商城类型；不可配置按钮不触发路由；
- 商品数量、字段、数据边界、路由、AppShell、正式菜单、公共 UI 组件和运行时依赖未修改。
