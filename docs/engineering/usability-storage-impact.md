# 便捷性与存储跨模块影响

## 数据事实来源

| 数据事实 | 来源 |
| --- | --- |
| 产品边界、用户流程与临时假设 | `docs/analysis/01-requirements-baseline.md`、`02-decision-log.md`、`03-open-questions.md`、`06-user-flows.md` |
| 页面、公共组件与验收范围 | `docs/analysis/04-information-architecture.md`、`05-page-inventory.md`、`08-page-component-mapping.md`、`09-prototype-acceptance-checklist.md` |
| 统一价格 | `src/features/pricing/data/priceCatalog.json` 与 `src/features/pricing` |
| 资源和关联对象 | `src/features/resources`、`src/features/storage`、`src/features/orders`、`src/features/operations` |
| 文件节点与容量统计 | `src/features/files`，文件大小汇总加系统预留占用 |

## 受影响模块

| 模块 | 同步内容 |
| --- | --- |
| 软件中心与产品导航 | 共用品牌基础；保留应用发现、版本、兼容性、目标资源和安装状态 |
| 我的资源 | 列表购买入口、空状态入口、详情同规格购买、存储和软件关联入口 |
| 存储管理 | 云硬盘/共享存储领域、购买、挂载、卸载、扩容、续期、文件管理 |
| 云服务器购买 | 新购存储、选择已有存储、暂不挂载、统一价格与挂载路径 |
| 订单与操作记录 | 存储购买、扩容、续期、挂载、卸载与文件操作 |
| 离线交付与验证 | Hash 路由、单 HTML、关系/价格/存储验证器 |

## 需要同步修改的入口

| 入口 | 目标 |
| --- | --- |
| 云服务器/物理机列表标题与空状态 | 带类型筛选进入资源商城 |
| 资源详情主要操作 | 购买同规格或同类整机 |
| 云服务器详情存储区 | 购买、挂载与文件管理 |
| 存储列表与空状态 | 购买存储 |
| 存储详情 | 文件管理、挂载、扩容、续期、订单、操作记录、购买同类型 |
| 订单列表与详情 | 购买资源并进入关联资源或存储 |
| 软件详情 | 直接选择版本和目标资源安装 |
| 404 | 返回资源商城或进入控制台 |

## 新增路由

| 路由 | 用途 |
| --- | --- |
| `#/console/storage/purchase` | 存储类型、规格、挂载与价格摘要的一页式购买 |
| `#/console/storage/:storageId/files` | 适用存储的文件管理器 |

## 关联数据关系

| 关系 | 约束 |
| --- | --- |
| 存储 SKU → 价格 | 每个存储 SKU 必须存在统一 GB/月价格 |
| 云硬盘 → 资源 | 最多一个同站点云服务器挂载；未初始化或未挂载时不开放文件管理 |
| 共享存储 → 资源 | 可挂载多个同站点适用资源，每个关系保存路径与读写模式 |
| 存储 → 订单 | 购买、扩容、续期、挂载、卸载保存价格或零费用快照 |
| 文件节点 → 存储 | 存储有效、父目录有效、同级唯一、路径可解析且无目录循环 |
| 文件大小 → 容量 | 文件大小汇总与系统预留形成已用容量，且不超过存储总容量 |
| 文件操作 → 操作记录 | 只记录对象路径、动作和结果，不记录本地文件内容 |
