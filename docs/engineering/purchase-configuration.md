# 购买配置

## 范围

云服务器和物理机配置页读取商城商品，完成配置编辑、实时摘要、字段校验、确认和提交。商品不存在、类型不匹配、不可配置和路由资源不存在均显示正式页面状态。

云服务器配置保持系统盘、数据存储、镜像和网络语义分离；物理机配置只包含适用的整机使用与网络意向，不混入云服务器磁盘、镜像或未确认的电源规则。数量、价格、审批、库存、支付、凭据与资源生命周期不被擅自定义。

## 数据与前端状态

配置初始数据位于 `src/features/purchase/data/`，商城商品通过 `marketplaceCatalog.ts` 的稳定 ID 直接读取。表单草稿以内存状态为主，并可选写入版本化 `sessionStorage`；存储不可用时不影响页面。切换商品、清除草稿和返回商城均保持既有确认交互。

`state/purchaseStore.ts` 负责提交配置、创建订单快照并追加操作记录。提交中的禁用状态用于防止重复操作，不包含人工网络延迟或远程失败模拟。成功反馈只表示配置已受理并等待资源准备或交付，不自动创建计算资源。

## 跨模块联动

配置提交生成稳定订单编号并进入订单详情。订单、商城商品和操作记录共享商品 ID 与订单编号；资源只有在内置初始数据明确关联时才提供入口。刷新后允许恢复内置初始状态。

## 路由

独立文件使用：

```text
#/marketplace/cloud-server/purchase?product=<商品 ID>
#/marketplace/physical-machine/purchase?product=<商品 ID>
```

Hash 路由支持直接打开、前进、后退和刷新，开发故障查询参数不再参与正式流程。
