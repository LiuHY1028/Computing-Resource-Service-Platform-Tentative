# 资源管理工程说明

## 领域模型与数据边界

资源领域位于 `src/features/resources/`，以 `CloudServerResource | PhysicalMachineResource` 作为统一联合类型。公共字段覆盖资源身份、站点、规格、状态、IP、有效期、项目与用途、责任主体、监控、软件和操作记录；云服务器保留镜像、30 GB 系统盘、数据盘和端口规则，物理机保留整机型号、主机名、操作系统、整机存储摘要和 BMC 信息可见状态。

`resourceRepository.ts` 是页面唯一数据入口，提供列表查询、详情读取、筛选选项、操作记录和操作提交。当前数据与操作结果仅保存在浏览器内存中，刷新后重置；商城配置编号不会自动转为资源。

## 列表与详情

云服务器和物理机列表分别位于 `/resources/cloud-servers` 与 `/resources/physical-machines`。共享列表实现搜索、组合筛选、条件标签、分页及 Loading、Error、Empty、No Result 状态，筛选与页码通过 URL 查询参数恢复。

详情路由在列表路由后追加 `/:resourceId`。共享详情骨架包含概览、监控、存储、网络与访问、软件与环境、操作记录六个 Tab，并依据资源联合类型展示专有字段。`tab` 查询参数用于恢复当前区域；未知资源 ID 显示资源缺失状态。

## 连接、监控与只读信息

`ConnectionInformation` 统一展示内外网 IP、SSH 用户与端口、认证方式、子网、网关、连接说明和可复制命令。未分配公网 IP 时提示通过企业网络、专线或跳板环境连接；资源未就绪时不生成命令；物理机 BMC 只展示权限状态，不包含登录信息。

监控面板使用 Repository 中的确定性序列与内联 SVG，提供最近 1 小时和最近 24 小时视图及数据更新时间。资源类型与计算类型决定 CPU、内存、GPU、显存、磁盘和网络指标是否出现，不接入第三方图表库，也不声明实时采集。

存储、网络规则、软件环境均为只读摘要。网络规则 Modal 只查看本地数据；软件入口复用现有软件中心路由，不在本模块实现安装、挂载、扩容或网络变更。

## 基础操作

云服务器按当前状态开放启动、停止、重启和修改名称；物理机仅开放修改名称，电源操作在需求确认前保持禁用。资源释放对两类资源均保持危险语义和禁用原因。

操作使用公共 Modal、Button、Form 与 Input。提交中禁止重复操作；失败保留弹窗并允许重试；提交成功后更新同一内存 Repository、资源状态和操作记录，并仅提示“操作请求已提交，状态更新中”。这些限制属于前端交互保护，不是正式资源生命周期状态机。

## 公共组件与后续接入

页面复用 AppShell、Container、TitleBarTabs、UnderlineTabs、Table、Pagination、Tooltip、Modal、Form、Input、Select、Progress 和 Button，资源领域入口由 `src/features/resources/index.ts` 统一导出。

后续真实接入应保留 Repository 接口，由 API 适配器替换内存实现，并分别接入：

- 资源查询、操作受理、执行状态和操作记录服务；
- 监控指标查询与更新时间；
- 存储、镜像、软件和网络模块的详情链接或只读数据；
- 经业务确认后的物理机电源、资源释放和 BMC 授权能力。

当前不包含真实基础设施调用、密码或密钥、正式计费、订单、审批和复杂权限规则。
