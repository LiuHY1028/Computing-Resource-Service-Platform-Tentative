# 资源管理工程说明

## 数据与状态

资源领域位于 `src/features/resources/`。`CloudServerResource | PhysicalMachineResource` 统一计算资源身份、站点、规格、状态、连接、监控、软件和操作记录；云服务器与物理机的专有字段保持分离。

`state/resourceStore.ts` 直接读取随应用打包的初始资源，并提供筛选、详情、操作记录和前端操作。修改名称、启动、停止与重启会更新当前页面会话中的资源状态，并追加统一操作记录；刷新后可恢复内置初始数据。

## 页面与交互

云服务器和物理机列表支持搜索、组合筛选、条件标签、分页、空数据和无结果状态。默认列表采用固定布局和组合单元格，在展开侧栏的 1366 与 1920 宽度下不产生横向滚动；资源、状态和操作列固定保留。列设置只管理扩展列，主动开启扩展列后允许表格内部滚动，“恢复默认列”会关闭全部扩展列。

连接信息支持复制 SSH 命令：优先使用 Clipboard API，不可用时回退到临时文本选择；两条路径均失败时显示明确反馈。监控序列和内联 SVG 随应用打包，不声明实时采集。

资源操作使用公共 Modal、Form、Input 与 Button。提交期间阻止重复操作，字段校验失败保留在表单中；提交成功后更新内存状态并给出正式的受理反馈。物理机电源与资源释放等未确认能力继续禁用并显示原因。

详情页通过稳定资源 ID 读取概览、计费或费用期限、监控、存储、网络、软件与操作记录，未知 ID 显示资源不存在。当前周期金额读取资源价格快照，续费和延期读取当前价目并在提交时生成订单快照。

## 跨模块边界

资源 ID 关联存储挂载、镜像、软件安装、网络规则、订单和操作记录。价格计算委托 `src/features/pricing/`；资源领域不生成支付、审批、库存、凭据或外部基础设施结果。
