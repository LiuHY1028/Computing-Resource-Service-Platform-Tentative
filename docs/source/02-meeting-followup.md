# 会后需求补充

## 系统盘与数据盘

会议结束后重新确认：产品中仍然需要保留“系统盘”和“数据盘”的区分。

### 系统盘

- 默认系统盘容量暂定为30 GB。
- 原始讨论中的“30G内存作为系统盘”属于口误，应理解为“30 GB系统盘容量”，不是内存容量。
- 系统盘在产品界面中作为用户可理解的存储配置项展示。
- 底层对应K8S中该Pod可占用的最大存储空间或存储配额。
- 产品界面不需要直接向普通用户暴露K8S Pod等底层实现细节。
- 系统盘是否允许调整、允许范围以及底层具体实现，仍需后续确认。

### 数据盘

数据盘用于持久化业务数据，与系统盘分开配置。

支持两种挂载方式：

1. 通过HostPath挂载到所在主机；
2. 通过NFS挂载到高性能共享存储。

产品界面需要明确区分：

- 系统盘；
- 本地数据存储；
- 高性能共享存储。

HostPath和NFS是否直接作为用户可见术语，需要结合目标用户的技术能力决定。
