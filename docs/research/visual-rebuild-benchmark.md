# 数据工作区与文件工作区视觉基准

| 参考对象 | 借鉴的结构 | 借鉴的交互 | 不采用的内容 |
| --- | --- | --- | --- |
| Ant Design Table、ProTable | 搜索、筛选、批量操作、列设置与表格组成连续工作区 | 排序、筛选、选择、密度和列显示集中在同一控制带 | 文档示例式堆叠、独立大筛选卡、默认品牌外观 |
| MUI X Data Grid | 表头、行、状态页和分页形成完整数据视图 | 列管理、密度、键盘操作和选择状态即时反馈 | 高级授权功能、外部运行时依赖、组件库默认皮肤 |
| Carbon Data Table | 用精细分隔和尺寸档位组织高密度数据 | 批量操作在选择后替换默认工具栏，状态与行操作保持克制 | 粗重外框、企业品牌视觉、与领域无关的通用列 |
| Fluent 2 | 页面背景、工作区、浮层使用清晰 Surface 层级 | Hover、Focus、Selection 和命令操作保持同一反馈语言 | 大面积装饰性阴影、照搬品牌色和图标资产 |
| 阿里云云盘、ECS、NAS 与 OSS 控制台 | 资源概览、搜索筛选和资源列表按任务顺序衔接 | 名称进入详情，少量主操作直达，其余操作收进菜单 | 复杂云平台导航、广告入口、真实计费和基础设施规则 |
| 腾讯云 CBS、CFS、CVM 与 COSBrowser | 资源主信息与规格、挂载、期限组合显示；文件操作集中 | 自定义列、批量操作、文件搜索预览和传输任务反馈 | 账号、地域、权限和对象存储专有规则 |
| 华为云 EVS、SFS 与 OBS Browser+ | 单一列表工作区承载筛选、状态和操作；文件按目录浏览 | 名称跳转详情、更多菜单、前缀搜索、上传下载任务 | 云厂商项目体系、跨区域能力和服务端结果 |
| 百度智能云云盘、CFS 与云服务器 | 页面标题、主操作和紧凑列表形成清晰主线 | 资源名称/ID搜索，行内挂载或管理操作，状态就近展示 | 旧式全边框表格、厂商控制台框架和真实资源状态 |
| OneDrive Web | 左侧快速访问、中部文件主区、按需详情面板 | 统一命令栏、列表/网格、排序、选择、详情和最近访问 | 营销页素材、Microsoft 品牌资产和在线协作能力 |
| Dropbox Web | 文件夹层级、搜索与文件主视图围绕查找任务组织 | 批量选择、移动、分享入口和清晰的文件反馈 | 分享、成员协作、云同步与外部服务结果 |
| Google Drive | 导航、文件区和详情活动面板分工明确 | 列表/网格切换、文件夹优先、右键菜单、预览和详情 | 在线编辑、共享权限、智能推荐和 Google 品牌元素 |
| macOS Finder、Windows 文件资源管理器 | 侧栏、地址/面包屑、文件区与可开关 Inspector 组成桌面工作台 | 前进后退、快捷访问、选择后操作、预览、拖拽和上下文菜单 | 操作系统窗口装饰、本地磁盘能力和系统级权限 |
