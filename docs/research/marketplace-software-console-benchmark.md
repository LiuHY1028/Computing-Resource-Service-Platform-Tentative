# 资源商城、软件中心与控制台拆分竞品研究

| 能力 | 竞品做法 | 当前项目现状 | 是否采纳 | 备注 |
|---|---|---|---|---|
| 前台产品与控制台边界 | 云厂商用产品站承载介绍、选型和购买入口，用控制台承载已购资源管理；购买完成后回到实例列表或详情 | 商城、软件中心和后台管理当前共用 `AppShell` 与侧栏 | 是 | 拆为三套布局；参考[华为云 ECS 产品页](https://www.huaweicloud.com/product/ecs.html)与[购买后返回实例列表](https://support.huaweicloud.com/usermanual-ecs/ecs_03_0113.html) |
| 资源发现 | 产品页先用价值主张和场景建立理解，再给推荐规格、地域、核心参数、价格和购买入口 | 已有筛选、规格卡、价格和购买配置，但仍有明显控制台目录感 | 是 | 使用独立 Hero、资源能力概览、筛选和商品卡；参考[腾讯云 CVM](https://cloud.tencent.com/product/cvm)与[华为云 BMS](https://www.huaweicloud.com/product/bms.html) |
| GPU / 整机表达 | GPU 产品突出卡型、卡数、显存、CPU、内存；裸金属突出专属硬件、整机规格及云能力兼容 | 已有云服务器 / 物理机双类型和 GPU 规格数据 | 是 | 保留现有领域模型，将 GPU、CPU、内存和站点放在卡片主信息层；参考[百度 GPU 规格](https://cloud.baidu.com/product-price/gpu.html)与[百度裸金属](https://cloud.baidu.com/product/bbc.html) |
| 购买配置 | 购买页按地域、规格、镜像、存储、网络等分组，持续显示配置摘要和价格 | 已有两类购买页、草稿、价格汇总和确认提交 | 是 | 只重做独立购买布局和跨区路径，不引入竞品计费或交付规则；参考[阿里云 GPU 实例创建](https://help.aliyun.com/zh/egs/user-guide/create-a-gpu-instance/) |
| 软件发现 | 云市场以精选区、热门分类、交付方式、榜单和搜索共同组织发现，不以后台表格为主 | 软件页当前是控制台内目录 | 是 | 采用应用商店式精选区、分类轨道、搜索筛选与软件目录；参考[腾讯云云市场](https://market.cloud.tencent.com/)和[华为云云商店](https://marketplace.huaweicloud.com/) |
| 软件筛选 | 软件市场按分类、交付方式、价格/授权策略、属性和发布时间等组合筛选 | 已有分类、兼容性、安装状态与目标资源逻辑 | 部分 | 采纳分类、操作系统、适用资源、费用策略和安装状态；不引入未确认的销售或服务商规则；参考[阿里云商品列表](https://market.aliyun.com/products) |
| 软件详情与交付 | 商品详情突出版本/规格、发布方、交付方式和适用环境；镜像类软件与云服务器创建强关联 | 当前通过卡片和安装弹窗选择目标资源 | 是 | 增加页面内详情区域，保留版本、兼容性、目标资源选择和安装请求；参考[百度镜像交付说明](https://cloud.baidu.com/doc/Market/s/Nkam28o6e) |
| 软件中心视觉 | 应用市场使用图标、分类导航、专题/榜单与更内容化的卡片，和计算产品页节奏不同 | 商城与软件页共用同一控制台视觉体系 | 是 | 软件中心采用深色编辑部式头部、图标矩阵和分层目录；不复刻商城 Hero + 商品卡模板 |
| 跨区入口 | 产品页提供购买、文档、控制台入口；控制台提供再次购买、同配置购买及关联服务入口 | 跨模块入口存在，但路径无前台/控制台边界 | 是 | 三套顶栏互相可达；控制台侧栏只放后台模块，前台入口放顶栏；参考[腾讯云 CVM](https://cloud.tencent.com/product/cvm)与[华为云同配置购买](https://support.huaweicloud.com/usermanual-ecs/ecs_03_0113.html) |
| 控制台信息密度 | 控制台围绕资源列表、详情、配置、操作与记录，强调稳定导航和任务效率 | 现有后台页面和公共组件已较完整 | 是 | 保留控制台 UI 规范、公共组件和交互，只迁移路径、顶部全局入口与关联跳转 |
