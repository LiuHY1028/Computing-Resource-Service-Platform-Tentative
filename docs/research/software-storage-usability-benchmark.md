# 软件、存储与便捷性基准

| 能力 | 行业常见做法 | 当前问题 | 采纳方案 |
| --- | --- | --- | --- |
| 软件中心品牌关系 | [阿里云云市场](https://market.aliyun.com/products)、[腾讯云云市场](https://market.cloud.tencent.com/)、[华为云云商店](https://marketplace.huaweicloud.com/)沿用主站品牌导航、字体与基础控件，用内容编排区分云产品商城与应用目录 | 整页深色编辑器风格与资源商城割裂 | 共用品牌导航、蓝色主色、字体、容器、按钮和页脚；软件中心以浅色内容页、靛紫辅助色和局部深色精选卡形成差异 |
| 软件发现 | 官方市场普遍提供全局搜索、分类、交付方式、价格策略与精选内容 | 分类入口偏重，搜索和筛选缺少内容发现节奏 | 使用克制导视区、热门分类快捷入口、横向分类与精选软件区 |
| 应用卡片 | 官方目录将名称、发布方、版本、适用环境、交付方式和费用策略放在同一决策层级 | 信息需要跨区域拼接，安装入口不够自然 | 卡片直接呈现版本、CPU/GPU、操作系统、费用策略和安装状态，并保留详情入口 |
| 安装流程 | 市场详情先说明兼容环境，再选择版本和目标资源并提交安装 | 详情、目标资源和安装状态之间存在跳转断点 | 详情内完成版本、目标资源与兼容性判断，提交后进入处理中状态并关联资源和操作记录 |
| 独立云硬盘 | [阿里云数据盘](https://help.aliyun.com/zh/ecs/user-guide/attach-a-data-disk)、[腾讯云 CBS](https://intl.cloud.tencent.com/zh/document/product/362)、[百度智能云 CDS](https://cloud.baidu.com/doc/CDS/s/vketf9y3k)均采用独立创建、同站点挂载、初始化、扩容、卸载和续期 | 本地主机路径被当作独立可购存储，语义错误 | 改为独立云硬盘；一次挂载一台同站点云服务器，记录设备、文件系统、初始化、IOPS 与吞吐 |
| 高性能共享存储 | [腾讯云 CFS](https://cloud.tencent.com/product/cfs)、[百度智能云 CFS](https://cloud.baidu.com/doc/CFS/index.html)以文件系统协议支持多个计算资源和独立挂载路径 | 已有共享存储只有单一挂载展示，缺少批量关系管理 | 支持 NFS/SMB、多资源挂载、独立路径与读写模式，并提供文件管理 |
| 容量与价格 | 官方块存储和文件存储通常按类型、性能、容量与周期报价，扩容和续期保留费用快照 | 价格目录存在本地容量包，购买、扩容和续期未统一 | 云硬盘与共享存储全部按 GB/月计价，按性能等级区分 SKU，由统一价格目录计算 |
| 文件管理 | [腾讯云 COSBrowser](https://cloud.tencent.com/document/product/436/11366)、[百度智能云 BOS 桌面工具](https://cloud.baidu.com/doc/BOS/s/Uk52fnig1)提供目录树、列表、搜索、预览、批量上传下载、复制移动与任务列表 | 当前只有文件表格，没有桌面文件管理器结构与任务反馈 | 实现工具栏、目录树、列表/网格、详情面板、预览、目标目录选择器和本地任务中心 |
| 上传与下载 | 桌面工具以批量任务呈现进度、结果、失败原因与重试 | 离线边界下缺少可信的文件交互模型 | 使用浏览器 File API、Blob 与对象 URL，仅更新当前前端状态；任务快速完成但保留完整反馈结构 |
| 管理页便捷入口 | 官方控制台通常在标题区放主要操作，在空状态和详情关联区提供下一步 | 列表购买、详情关联操作和空状态存在绕路 | 每页仅保留一项首要操作；详情直达商城、存储、软件、订单或操作记录，并保留查询上下文 |
